### Sobre o projeto
Programa em Python que calcula desconto para compras:
- Compras abaixo de R$ 200,00 = 5% de desconto
- Compras de R$ 200,00 a R$ 300,00 = 10% de desconto  
- Compras acima de R$ 300,00 = 15% de desconto

### Como usar
Digite o valor da compra e o programa mostra o desconto e o valor final.
